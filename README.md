🦆 Random Duck Images

A fun and simple web project that displays random duck images every time the webpage is reloaded! 🐥

Built using HTML, CSS, and JavaScript, this project brings a little fun to your browsing experience by showing a different duck image whenever you refresh the page.

✨ Features
🦆 Displays random duck images.
🔄 Loads a new image when the webpage is reloaded.
🎨 Simple and attractive user interface.
📱 Responsive webpage design.
⚡ Lightweight and easy to use.
🛠️ Technologies Used
HTML – Structure of the webpage.
CSS – Styling and layout.
JavaScript – Random image loading functionality.
